# 设计参考提取记录（DESIGN.md）

> 对象：设计参考 `设计参考.svg`（2968×1760，110MB，Figma 类工具导出）
> 用途：小丑牌·腕上版 UI 重设计的视觉规范来源

## 1. 设计稿内容概述

该 SVG 是 **Vela 手表 UI 设计规范模板**（组件规格表），画布 2968×1760，包含：

- 7 个 336×480 圆角屏幕 mockup（页面标题/列表/空态/进度/输入法/画廊等通用界面）
- 组件规格：列表行、药丸按钮、进度条、数字键盘、图片瓦片、毛玻璃面板（backdrop-blur）
- 12 张内嵌位图：6 张样例照片（画廊占位）+ 1 张扁平图标 + 5 个透明底 UI 图标
- 文字全部转曲（outline path），经栅格化 + Windows OCR（zh-Hans）还原标注

官方 UI 指南出处：https://iot.mi.com/vela/quickapp/zh/guide/start/user-interface.html

## 4. 落地映射（游戏 UI 重设计）

| 游戏界面 | 采用的设计模式 |
|----------|----------------|
| 主菜单 | 黑底 + 白色大标题 + 药丸按钮（主 #0D6EFF / 次 #262626）+ 次文字行 |
| 对局-顶部 | 状态行模式（`盲注 N / 出牌 n / 弃牌 n`，#D8D8D8 20px） |
| 对局-分数 | 大数字模式（52px 粗体白）+ `/ 目标` 次文字 |
| 对局-进度 | 进度条模式（progress 组件，rx3 高 6，得分/目标） |
| 对局-小丑栏 | 弱底纹图标槽模式（64×64 rx20 rgba(255,255,255,0.06)） |
| 对局-手牌 | 选中态改用主强调蓝框 `#0D6EFF`（原金色） |
| 对局-按钮 | 主按钮 #0D6EFF（出牌）/ 次按钮 #262626 + 负向色文字（弃牌 #EA5130） |
| 小丑三选一 | 缩略图列表行模式（rx36 行 + 92×92 rx24 缩略槽 + 标题/描述） |
| 结算 | 大数字模式（60px）+ 药丸按钮组 |
| 规则页 | 列表行卡片模式（#262626 rx36 行）+ 分组标题 |
